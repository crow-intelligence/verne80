# Extractions

One file per chapter, named exactly `chapter_NN.json` — zero-padded, matching
`data/chapters/` and `data/prompts/`.

Paste Gemini's response here raw. Markdown fences and a line of preamble before the object
are both tolerated by the loader; there is no need to tidy them by hand.

**These are committed.** They are small, hand-verified, and expensive to regenerate — project
data, not build output.

See `data/prompts/README.md` for the paste workflow and what the validator checks.
